AI locale Local AI

Configurare Ollama (opzionale) Optional: Ollama for AI

Ollama ti permette di eseguire modelli AI grandi in locale, senza inviare dati a servizi cloud. Richiesto per le funzioni AI di CiteMind. Ollama allows you to run large AI models locally, without sending data to cloud services. Required for CiteMind's AI features.

1️⃣

Installa Ollama Install Ollama

Scarica e installa Ollama dal sito ufficiale. È disponibile per Windows, macOS e Linux. Download and install Ollama from the official website. Available for Windows, macOS and Linux.

→ ollama.ai
2️⃣

Scarica il modello gemma4 Download gemma4 model

Il modello consigliato è gemma4 di Google. Ottimo equilibrio tra qualità e velocità su hardware consumer. The recommended model is Google's gemma4. Great balance of quality and speed on consumer hardware.

ollama pull gemma4

CiteMind si connette ad Ollama tramite l'API REST locale su http://localhost:11434. Assicurati che il servizio Ollama sia avviato prima di usare le funzioni AI. In Impostazioni → AI puoi modificare l'endpoint e il modello predefinito. CiteMind connects to Ollama via the local REST API at http://localhost:11434. Ensure the Ollama service is running before using AI features. In Settings → AI you can change the default endpoint and model.

Aggiornamenti Updates

Auto-update da GitHub Auto-update from GitHub

CiteMind controlla automaticamente la presenza di nuove versioni al lancio, interrogando le GitHub Releases API. Quando è disponibile un aggiornamento, una notifica discreta appare in basso. Puoi aggiornare con un click senza uscire dall'applicazione. CiteMind automatically checks for new versions at launch by querying the GitHub Releases API. When an update is available, a discreet notification appears at the bottom. You can update with one click without leaving the application.
