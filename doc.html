Guida a CiteMind CiteMind Guide

Tutto quello che devi sapere per iniziare a usare CiteMind e sfruttarne al massimo le funzionalità avanzate. Everything you need to know to start using CiteMind and make the most of its advanced features.

🚀 Quick Start

Avvia CiteMind lanciando python main.py (da sorgente) o il file CiteMind.exe (Windows). Al primo avvio viene creato automaticamente il database SQLite nella cartella utente. Start CiteMind by running python main.py (from source) or the CiteMind.exe file (Windows). On first launch, the SQLite database is automatically created in the user folder.

Primo import in 3 passi First import in 3 steps

  • 1. Trascina un file PDF direttamente sulla finestra principale di CiteMind. Drag and drop a PDF file directly onto the main window of CiteMind.
  • 2. La pipeline di import si avvia automaticamente: estrazione metadati, ricerca DOI, arricchimento API. The import pipeline starts automatically: metadata extraction, DOI search, API enrichment.
  • 3. La voce bibliografica appare nella lista, completa di titolo, autori, anno, journal e abstract. The bibliographic entry appears in the list, complete with title, authors, year, journal and abstract.

💡 Suggerimento: Per ottenere risultati migliori, usa PDF con testo selezionabile (non scansioni). Per PDF scansionati è disponibile l'OCR tramite Tesseract, attivabile nelle Impostazioni. Tip: For best results, use PDFs with selectable text (not scans). For scanned PDFs, OCR via Tesseract is available, which can be activated in the Settings.

📥 Importare riferimenti 📥 Importing references

CiteMind supporta molteplici modalità di import, adatte a diversi flussi di lavoro accademici. CiteMind supports multiple import modes, suitable for different academic workflows.

Drag & Drop PDF

Il metodo più rapido. Trascina uno o più PDF sulla finestra principale. CiteMind processa i file in parallelo e mostra il progresso per ciascuno. Puoi trascinare anche intere cartelle. The fastest method. Drag one or more PDFs onto the main window. CiteMind processes the files in parallel and shows the progress for each. You can also drag entire folders.

DOI diretto Direct DOI

Incolla un DOI nel campo di ricerca rapida (in alto nella toolbar) e premi Invio. CiteMind interroga Crossref e recupera tutti i metadati disponibili in pochi secondi. Paste a DOI into the quick search field (top of the toolbar) and press Enter. CiteMind queries Crossref and retrieves all available metadata in seconds.

File BibTeX (.bib) BibTeX files (.bib)

Vai su File → Importa → BibTeX. Seleziona il file .bib. CiteMind importa tutte le voci del file, preservando i campi già presenti e arricchendo quelli mancanti dove possibile. Go to File → Import → BibTeX. Select the .bib file. CiteMind imports all entries from the file, preserving existing fields and enriching missing ones where possible.

File RIS RIS files

Compatibile con l'export di Zotero, Mendeley, EndNote e molte banche dati accademiche. Usa File → Importa → RIS. Compatible with Zotero, Mendeley, EndNote export and many academic databases. Use File → Import → RIS.

CSV batch

Importa da un foglio di calcolo. Il formato CSV richiede almeno le colonne title e authors. Puoi mappare le colonne personalizzate nella finestra di preview prima di confermare l'import. Import from a spreadsheet. The CSV format requires at least the title and authors columns. You can map custom columns in the preview window before confirming the import.

URL web Web URL

Per aggiungere risorse web alla sitografia, incolla l'URL nel campo DOI/URL e seleziona il tipo "Sitography". CiteMind recupera automaticamente titolo, autore e data dalla pagina. To add web resources to the sitography, paste the URL into the DOI/URL field and select the "Sitography" type. CiteMind automatically retrieves the title, author and date from the page.

📚 Tipi di voce (Entry Types) 📚 Entry Types

Ogni voce in CiteMind appartiene a uno dei tre tipi principali, selezionabile al momento della creazione o modifica. Each entry in CiteMind belongs to one of three main types, selectable upon creation or modification.

Bibliography

Per fonti accademiche tradizionali. Include tutti i campi standard (titolo, autori, anno, journal/editore, volume, pagine, DOI, abstract, keyword). Supporta i seguenti pub types: For traditional academic sources. Includes all standard fields (title, authors, year, journal/publisher, volume, pages, DOI, abstract, keywords). Supports the following pub types:

article book chapter conference report

Sitography

Per risorse web e contenuti digitali. Campi specifici: URL, data di accesso, nome del sito, autore (se disponibile). Pub type: web. La data di accesso viene registrata automaticamente al momento dell'import. For web resources and digital content. Specific fields: URL, access date, site name, author (if available). Pub type: web. The access date is recorded automatically upon import.

Tesi Thesis

Per tesi accademiche (laurea triennale, magistrale, dottorato, specializzazione). Campi specifici: ateneo, relatore, correlatore, anno accademico, tipo di tesi, dipartimento. Pub type: thesis. For academic theses (bachelor, master, PhD). Specific fields: institution, supervisor, co-supervisor, academic year, thesis type, department. Pub type: thesis.

🤖 Configurare Ollama per l'AI 🤖 Setting up Ollama for AI

Ollama permette a CiteMind di usare modelli AI grandi in locale, senza dipendere da API cloud. Tutte le elaborazioni avvengono sul tuo computer. Ollama allows CiteMind to use large AI models locally, without relying on cloud APIs. All processing happens on your computer.

Installazione Installation

Scarica e installa Ollama da ollama.ai. Al termine dell'installazione, avvia il servizio. Download and install Ollama from ollama.ai. After installation, start the service.

Scaricare il modello consigliato Downloading the recommended model

ollama pull gemma4

Configurazione in CiteMind Configuration in CiteMind

Vai su Impostazioni → AI. Verifica che i seguenti valori siano corretti: Go to Settings → AI. Verify that the following values are correct:

# Endpoint Ollama (default) # Ollama Endpoint (default) Endpoint: http://localhost:11434 # Modello consigliato # Recommended model Modello: gemma4

Funzioni AI disponibili Available AI features

  • Note da PDF: genera automaticamente un riassunto del documento Notes from PDF: automatically generates a summary of the document
  • AI Topics: estrae topic tematici dal contenuto del PDF AI Topics: extracts thematic topics from the PDF content
  • Metadati fallback: inferisce titolo, autori, anno se non trovati dalle API Metadata fallback: infers title, authors, year if not found by APIs
  • Ricerca semantica: usa embedding per trovare documenti concettualmente simili Semantic search: uses embeddings to find conceptually similar documents

Privacy: Quando si usa Ollama, nessun testo viene inviato a server esterni. Tutti i dati rimangono sul computer dell'utente. CiteMind non raccoglie dati di utilizzo. Privacy: When using Ollama, no text is sent to external servers. All data remains on the user's computer. CiteMind does not collect usage data.

📊 Knowledge Graph

Il Knowledge Graph visualizza la tua biblioteca come una rete di relazioni tra documenti e concetti tematici. The Knowledge Graph visualises your library as a network of relationships between documents and thematic concepts.

Come aprire il Knowledge Graph How to open the Knowledge Graph

Usa il menu Vista → Knowledge Graph o la scorciatoia Ctrl+G. Il grafo si aggiorna automaticamente ad ogni import. Use the menu View → Knowledge Graph or the shortcut Ctrl+G. The graph updates automatically with each import.

Cosa mostra il grafo What the graph shows

  • Nodi blu (documenti): ogni voce bibliografica nel database Blue nodes (documents): each bibliographic entry in the database
  • Nodi viola (keyword): termini estratti via TF-IDF dal corpus Purple nodes (keywords): terms extracted via TF-IDF from the corpus
  • Archi Jaccard: connettono documenti con keyword in comune (soglia ≥ 0.35) Jaccard edges: connect documents with shared keywords (threshold ≥ 0.35)
  • Archi semantici: basati sulla similarità coseno tra embedding Semantic edges: based on cosine similarity between embeddings
  • Archi DAG: citazioni esplicite tra documenti (@references) DAG edges: explicit citations between documents (@references)

Interazione Interaction

Puoi zoomare con la rotella del mouse, trascinare i nodi per riorganizzare il layout, cliccare su un nodo per vedere il dettaglio del documento, e filtrare per tipo di arco usando i controlli in overlay. You can zoom with the mouse wheel, drag nodes to reorganise the layout, click on a node to see document details, and filter by edge type using the overlay controls.

🎨 Temi 🎨 Themes

🌑

Dark (predefinito / default)

Tema scuro con palette viola/indigo. Ottimale per lunghe sessioni di lavoro e ambienti con poca luce. Riduce l'affaticamento visivo. Dark theme with purple/indigo palette. Optimal for long work sessions and low-light environments. Reduces eye strain.

☀️

Light

Tema chiaro ad alto contrasto. Ideale in ambienti luminosi o per chi preferisce interfacce simili a carta stampata. High contrast light theme. Ideal in bright environments or for those who prefer paper-like interfaces.

💻

Terminal

Tema ispirato ai terminali classici. Verde su nero, font monospace. Per chi ama l'estetica retrò e vuole una differenziazione netta dall'interfaccia OS. Theme inspired by classic terminals. Green on black, monospace font. For those who love retro aesthetics and want a clear differentiation from the OS interface.

📖

Ebook

Tema con sfondo color carta e testo seppia, ispirato agli e-reader. Ottimo per sessioni di lettura prolungate di note e abstract. Theme with paper-coloured background and sepia text, inspired by e-readers. Great for prolonged reading sessions of notes and abstracts.

Cambia tema da Impostazioni → Aspetto → Tema o dal menu a tendina nella toolbar. Il tema viene salvato tra le sessioni. Change the theme from Settings → Appearance → Theme or from the dropdown menu in the toolbar. The theme is saved between sessions.

📄 PDF Viewer

CiteMind include un visualizzatore PDF integrato con supporto ad annotazioni e OCR. CiteMind includes an integrated PDF viewer with support for annotations and OCR.

  • Annotazioni: evidenzia testo, aggiungi note a margine direttamente nel PDF Annotations: highlight text, add marginal notes directly in the PDF
  • OCR: per PDF scansionati, usa Tesseract per estrarre il testo (richiede installazione separata) OCR: for scanned PDFs, use Tesseract to extract text (requires separate installation)
  • Sincronizzazione note: le annotazioni vengono salvate nel database e associate alla voce bibliografica Note synchronization: annotations are saved in the database and associated with the bibliographic entry

Apri il PDF Viewer doppio-cliccando su una voce che ha un PDF allegato, o tramite il pulsante "Apri PDF" nel pannello dettagli. Open the PDF Viewer by double-clicking on an entry that has an attached PDF, or via the "Open PDF" button in the details panel.
