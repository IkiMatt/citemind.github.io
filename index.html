CiteMind

Il gestore di citazioni accademiche potenziato dall'AI. Import intelligente, Knowledge Graph e stili bibliografici professionali in un'unica app desktop. The academic citation manager powered by AI. Smart import, Knowledge Graph and professional bibliography styles in a single desktop app.

Funzionalità principali Key features

Perché CiteMind? Why CiteMind?

Tutto ciò di cui hai bisogno per gestire la bibliografia accademica, dal primo import alla citazione formattata, in un'unica applicazione open source. Everything you need to manage academic bibliography, from the first import to the formatted citation, in a single open-source application.

🚀

Import Intelligente Smart Import

Trascina PDF, file BibTeX, RIS, CSV o incolla un DOI. La pipeline automatica arricchisce i metadati interrogando Crossref, OpenAlex e Semantic Scholar, con AI fallback via Ollama. Drag-and-drop PDFs, BibTeX, RIS, CSV files or paste a DOI. The automatic pipeline enriches metadata by querying Crossref, OpenAlex and Semantic Scholar, with AI fallback via Ollama.

🤖

Integrazione AI Locale Local AI Integration

Grazie a Ollama e il modello gemma4, CiteMind genera note a partire dal testo dei PDF, estrae topic tematici e arricchisce in locale i metadati mancanti, senza inviare dati a server esterni. Using Ollama and the gemma4 model, CiteMind generates notes from PDF text, extracts thematic topics and locally enriches missing metadata — without sending data to external servers.

📊

Knowledge Graph Knowledge Graph

Visualizza le relazioni tra i tuoi documenti come un grafo interattivo con forza. I nodi rappresentano documenti e keyword; gli archi sono calcolati tramite Jaccard overlap e similarità semantica. Visualise relationships between your documents as an interactive force-directed graph. Nodes represent documents and keywords; edges are computed via Jaccard overlap and semantic similarity.

📄

Stili di Citazione Citation Styles

Genera citazioni formattate in APA 7th, MLA, Chicago Author-Date, Harvard e Preistoria Alpina. Supporto a stili custom configurabili dall'utente. Export in DOCX, BibTeX, BibLaTeX e PDF. Generate formatted citations in APA 7th, MLA, Chicago Author-Date, Harvard and Preistoria Alpina. Support for user-defined custom styles. Export to DOCX, BibTeX, BibLaTeX and PDF.

🔍

Ricerca Semantica Semantic Search

Oltre alla full-text search (SQLite FTS5 su titolo, autori, journal, note), CiteMind supporta la ricerca semantica tramite vettori embedding e cosine similarity per trovare documenti concettualmente correlati. Beyond full-text search (SQLite FTS5 on title, authors, journal, notes), CiteMind supports semantic search via embedding vectors and cosine similarity to find conceptually related documents.

🎨

Temi e Personalizzazione Themes & Customisation

Quattro temi integrati: Dark, Light, Terminal e Ebook. Sidebar tematica, autosave, drag & drop nativo, Command Palette (Ctrl+Shift+P) e interfaccia localizzata (i18n). Four built-in themes: Dark, Light, Terminal and Ebook. Thematic sidebar, autosave, native drag & drop, Command Palette (Ctrl+Shift+P) and localised interface (i18n).

Tre tipi di voce bibliografica Three types of bibliographic entries

CiteMind organizza le tue fonti in tre categorie distinte, ognuna ottimizzata per il proprio contesto d'uso. CiteMind organises your sources into three distinct categories, each optimised for its context of use.

Tipo Type Descrizione Description Pub Types supportati Supported pub types
📚 Bibliography Fonti accademiche tradizionali: articoli, libri, capitoli, atti di convegno, report scientifici. Traditional academic sources: articles, books, chapters, conference papers, scientific reports. article book chapter conference report
🌐 Sitography Riferimenti a risorse web, pagine online, dataset e risorse digitali con URL e data di accesso. References to web resources, online pages, datasets and digital resources with URL and access date. web
🎓 Tesi Gestione dedicata per tesi di laurea, dottorato e specializzazione, con campi specifici per ateneo e relatore. Dedicated management for bachelor's, master's and doctoral theses, with specific fields for institution and supervisor. thesis
